CLI reference

Install

Python 3.10 or newer. pip install -e ".[hf]" inside a virtualenv works too.

Naming a neuron

Neurons are written as in the original tweets: L14 N8949 is layer 14, neuron 8949. In a mixture-of-experts model there is an expert in the middle: L11 E14 N370. Quote it on the command line, because of the spaces.

skrrt hunt

Runs all four stages and writes a report.

--model M
A Hugging Face model id or a path to a model (a .gguf file for llamacpp). Required.
--persona P|file.yaml
A built-in persona name or a path to your own persona file. Required.
--backend auto|hf|llamacpp default auto
How the model is run. See Backends.
--judge auto|jev|self default auto
Who grades the replies. See Judges.
--out DIR default runs/<model>-<persona>/
Where the run is written.
--layers A-B default all layers
Only search layers A through B.
--per-layer 8
How many top-ranked neurons per layer go into the screen.
--screen-doses 1,2
Doses tried in the screen.
--doses 0.5,0.75,1,1.5,2,3
The dose sweep in the confirm stage.
--finalists 10
How many screened neurons go on to confirm.
--controls 4
How many random control neurons are run alongside.
--max-tokens 100
Length limit for each generated reply.
--seed 0
Seed for the random choices, such as which control neurons are drawn.
--force
Redo stages that already have results instead of resuming.
--backend-arg key=value
Pass a setting straight to the backend. Repeatable.

skrrt personas

Lists the built-in personas.

skrrt new-persona

Writes a template persona file, NAME.yaml, for you to fill in. See Writing your own.

skrrt write-replies

Fills in the replies of a persona file by having a model answer in the persona's voice.

--model M
The target model.
--writer target|<id> default target
target has the target model write the replies under the persona's system prompt. An OpenRouter chat model id uses that model instead (needs OPENROUTER_API_KEY).

skrrt steer

Try a neuron. With a prompt it prints one steered reply. Without one it opens an interactive chat.

skrrt report

Rebuilds report.md and report.json from a run directory's stage files. Nothing is regenerated.

skrrt export-cvec

Writes the neuron's push as a llama.cpp control vector, for llama-server. See Serving a steered model.

The run directory

Each hunt writes to runs/<model>-<persona>/:

  • stage files for rank, screen and confirm;
  • report.md, the readable report;
  • report.json, the same content for scripts.

A run resumes where it stopped. Run the same skrrt hunt command again and finished work is kept. Use --force to start over.

Environment

OPENROUTER_API_KEY
Used by the Jev judge and by write-replies --writer <id>. Not needed with --judge self.
